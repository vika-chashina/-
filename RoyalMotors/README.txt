Royal Motors — простой учебный проект Windows Forms
Платформа: .NET Framework 4.8

Окна проекта:
- Авторизация
- Главное меню с кнопками перехода
- Регистрация
- Форма клиента
- Автомобили

Запуск:
1. Распакуйте архив.
2. Откройте RoyalMotors.sln в Visual Studio.
3. При необходимости установите .NET Framework 4.8 Developer Pack.
4. Нажмите F5.

Тестовые данные:
Клиент: client / client
Менеджер: manager / manager

Важно: это учебный пример. Данные регистрации и формы клиента не сохраняются в базе данных.
